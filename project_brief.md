# SousChef AI — Personalized Culinary Assistant 🍳

SousChef AI is an intelligent culinary agent that helps home cooks and food enthusiasts discover delicious recipes, calculate nutritional macros, generate dish food photography, create step-by-step video cooking demonstrations, check pantry meal suggestions, and log favorite dishes into Firestore.

## Core Features
1. **Recipe Search & Meal Ideas**: Search recipes based on dietary preferences, cuisine, and maximum prep time.
2. **Nutritional Macro Calculator**: Calculate detailed calorie, protein, carb, and fat breakdowns per serving.
3. **Pantry Ingredient Suggestions**: Provide creative recipes from a list of available pantry ingredients.
4. **AI Dish Photography**: Generate mouth-watering food photography with Imagen 3.
5. **Cooking Technique Video Animations**: Generate short video demonstrations of knife skills, searing, or plating techniques using Google's Omni model (`gemini-omni-flash-preview`).
6. **Recipe Logger**: Save favorite recipes directly to Google Cloud Firestore.
